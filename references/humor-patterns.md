# 原创幽默机制工具箱

> 用于理解笑点的“生成原理”，不是八个必须逐项填完的模板。优先挑最贴题的 1 个，必要时组合或自由创作。以下均为新创作示范，非豆包真实语录。

## 1. 先夸后损

**动作**：找真实或故意夸大的优点 → 给出与之冲突的事实 → 轻巧收尾。
- 情境：总说下周开始的计划。
- 示例：“你这个人最大的优点就是守信用，说下周开始，永远都是下周。”
- 避免：夸得无关、转头就对人格辱骂；不要所有句子固定以“可以啊”开头。

## 2. 逻辑偷换

**动作**：把两件表面关联但实际上不同的事严肃地拆开，推导一个明显荒诞的结论。
- 情境：办卡不去健身。
- 示例：“办卡是消费行为，健身是体育运动。你在消费这块已经运动得非常充分了。”
- 避免：在认真求知、医疗、财务、技术等内容中用假推理冒充真结论。

## 3. 身份反转

**动作**：把普通行为重新命名为一个夸张、有戏剧效果的角色身份。
- 情境：健身卡一次没用。
- 示例：“健身房全体员工应该给你颁个奖，年度沉默投资人。”
- 避免：把脆弱人群/经济困境当笑点。

## 4. 极度认真

**动作**：将日常小事包装为制度、科研、战略或重大历史议题；结论明显是玩笑。
- 情境：喝水忘了。
- 示例：“关于你今天有没有喝水这件事，我建议立即成立一个专项小组，先把杯子找出来。”
- 避免：太长、太像正式公告，直到结尾还没有笑点。

## 5. 预期落空

**动作**：让语气/行动预期逐渐变强，然后给出无害的泄气结局。
- 情境：朋友说“有本事来单挑”。
- 示例：“你等着，我马上过去——过去给你发个和平倡议书。”
- 避免：真实威胁或欺骗事实。

## 6. 夸张升级

**动作**：围绕同一个荒诞细节从小到大递进，最后停在最有趣的一处。
- 情境：打开购物车又下单。
- 示例：“你这购物车不叫购物车，叫物流行业年度振兴计划。”
- 避免：连续三段同义词轰炸、强行增加篇幅。

## 7. 嘴硬认怂

**动作**：强势宣言 → 现实条件突现 → 立刻认怂但嘴上不服。
- 情境：抢不到最后一块蛋糕。
- 示例：“这块蛋糕我今天势在必得……当然，你先吃。我主要负责气势。”
- 避免：反复用“踢到棉花”替代所有反差。

## 8. 荒诞拟人

**动作**：让物品/概念具备明确、有限的人类情绪或行为。
- 情境：一拖再拖的计划。
- 示例：“你的计划书现在最关心的事，可能是自己能不能熬到退休。”
- 避免：无关生造拟人、失去原来事实和对象。

## 组合原则

- “先夸后损 + 身份反转”适合犀利短吐槽；“极度认真 + 预期落空”适合正经荒诞；“嘴硬认怂 + 拟人”适合自嘲。
- 只要一句就能完成的，不硬扩成四句；用户要长排比或连续包袱再扩写。
- 不要为了“豆味”强行把每个角色都写成毒舌；单个指定角色的语言机制可以与其他人形成对照。
- 用户要求保留原意时先锁定断言：“建议先测试”不能被改成“直接上线”；幽默仅改说法，不翻转事实立场。

## 负面样本与定向修复

- **强塞语料**：“宝子，我最直白地告诉你，这个最直接、最清楚、最不绕弯……” → 删重复开场，保留一句最有用的判断。
- **空泛捧哏**：“哈哈你真的很有趣太搞笑了哈哈” → 回到话题具体矛盾，写出新视角。
- **过火**：“你这种人什么都不配做” → 不评价人格，改为评价可笑的具体事情。
- **假事实**：“经科学证实，每天熬夜让你更聪明” → 删除伪科学，必要时明确这是玩笑。
- **解释包袱**：“这个比喻很好笑是因为……” → 正常输出时删除解释（除非用户要求分析）。
- **机械强制反转**：用户纠正 AI 的数据错误，模型还说“千对万对都是我没错” → 明确认错、校正数据，不开玩笑掩盖错误。
