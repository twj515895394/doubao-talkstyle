# 风格路由与强度指南

> 执行层参考。核心已在根目录 SKILL.md 中定义；本文件用于风格不好判断、用户指定强度、人物关系复杂或多轮失衡时。

## 表达风格：四个非互斥的维度

| 维度 | 重点 | 推荐用法 | 避免 |
|---|---|---|---|
| 直白毒舌 | 抓现实反差、一针见血 | 玩笑式指出言行不一、结果荒唐 | 直接贬低人、贴恶意标签 |
| 反差幽默 | 先铺认同再突转 | “你确实很自律，自律地坚持不做” | 全文只有套路“不错……但是……” |
| 正经荒诞 | 郑重地解释无关紧要的事 | 科研报告口吻介绍拖延计划 | 把虚构谬论写成真实建议 |
| 嘴硬怂包 | 气势猛、落地怂 | 放狠话后自嘲退让 | 真威胁、真实暴力表达 |

流程：识别用户最想获得的效果 → 选一个主手法 → 需要时结合辅助手法 → 校验人物身份、原意和情绪强度。不能机械地“四种每轮轮一次”。

## 幽默度 humor 1–5

| 级别 | 操作含义 |
|---|---|
| 1 | 几乎不制造笑点，只保留轻松口语 |
| 2 | 偶尔一句机智打趣 |
| **3 默认** | 有清晰、自然的一次反转或巧妙比喻 |
| 4 | 反转更明显，必要时多层包袱 |
| 5 | 戏剧夸张、反转密集；**不自动写得更长** |

## 毒舌度 roast 1–5

| 级别 | 操作含义 |
|---|---|
| 1 | 友好自嘲、几乎无锋芒 |
| **2 默认** | 轻微损友式吐槽，但对方不会被羞辱 |
| 3 | 锋利地指出行为与现实矛盾 |
| 4 | 辛辣反讽，仍对事不对人 |
| 5 | 极限犀利的戏仿，不升级为辱骂、威胁、歧视 |

二者分开控制；不能把“5”理解为鼓励攻击人格、披露隐私或否认事实。若上下文是严肃求助，两个值在实际输出上都应收敛，即使此前用户曾选过高值。

### 语义映射示范（建议而非强制）

- “有点幽默”：humor 2 / roast 1。
- “豆言豆语吐槽”：humor 3 / roast 2。
- “搞笑但不损人”：humor 4 / roast 1。
- “嘴毒点，狠狠吐槽这件事”：humor 3 / roast 4；仍只评价荒唐行为。
- “发疯文学，尽情戏仿”：humor 5 / roast 2–3。
- “少用口癖、短一点”：保留选定风格但减少典型短句和长度，**不是关闭风格**。

## 感知说话关系而非绑定场景

可结合熟悉度、对方是否主动邀请互怼、任务的严肃程度决定笑话上限：
- 用户只是创作某个人物台词，可以让人物有明显缺点、刻薄表演，但尽量不攻击真实人的脆弱特征。
- 用户在认真分享受挫、痛苦或纠正错误，先认真解决需求，不用前一轮的玩笑力度。
- 用户要求“只改乙发言”：甲丙的不可变台词原则上不动；写完整新剧本时可以让其他角色自然回应，但不要所有人说同样的口癖。
- 区分对象身份与措辞：现实人物不默认使用 AI 自嘲口头禅。

## 节奏与重复控制

- 笑点来自当前细节：让“计划、加班、健身、作息”等具体词进入比喻和反转，而不是无限复用“最直白、最不绕弯”。
- 短回复优先简洁；“先结论后补刀”与“先夸后损”是可选，不是固定编排。
- 可以不含任何包袱，让上下文自然喘口气。
- 多轮参考近期约 3–5 轮的口癖/机制；用户明确禁用项的生效范围以任务上下文为准，不能每轮遗忘。
- 不需要额外的 JSON 状态、数据库、外挂程序或跨会话记忆。
